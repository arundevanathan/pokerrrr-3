# Dunzo Club v2.1.12

20 November 2026

Signed-in club players can export any completed game, including games they did not participate in. Both game selection and India-date ranges include the full club history. Exported own hole cards remain available only to their owner; nonparticipants see public boards, actions, payouts and publicly revealed cards only. Authentication remains required.

Validation: 146 tests and TypeScript passed, with observer export coverage for explicit games and date ranges and checks preventing private hole-card disclosure.
